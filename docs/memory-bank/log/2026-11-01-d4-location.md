# Location (P4 slice 5, D4; feat/d4-location)

Book C-01, F-010, F-240, Q-107, board States 02, 03.

## What's there

- `features/pick-place`: `usePlace` (near me, a typed place or a city, kept in `localStorage` and shared by everything on the
  page through `useSyncExternalStore`), `LocationBanner` (the offer, then «Location off» with its help sheet), `WhereField`.
- Nothing asks for the location until a button does. No `Permissions-Policy` blocks geolocation on the live site (checked).
- `SearchPage`: the address wins (`near=`, `city=`, `area=`), so a shared link shows what it says; otherwise the kept place. The
  radius select shows when the search has a position, and the empty state widens it one step.
- Home: «Free today near you» once located, otherwise the popular list.

## Traps

- `ComboboxInput` dropped a `ref`: it uses its own, so «I'll type an address» did nothing until a story pressed it. It passes one
  through now.
- `setState` in an effect fails the lint, which is why the place reads through `useSyncExternalStore`, with the server's snapshot
  empty so the first render agrees with the server's page.
- Stories start with `beforeEach` clearing `yeral.place`: it would otherwise carry over from the story before.

## Left

- The phone's full-screen search sheet (Mobile 1) and suggestions in «What?» (`sdk.catalog.suggest`, built, not used).
