## Decisions

- Plain `toast(message)` = success (the check): the apps' 180 plain calls are confirmations («Saved», «Copied»,
  «Removed»); only the error sites were renamed. A toast that is neither should say so by name (`toast.info`).
- An error toast with an action gets the × as well as the action: the board's note says it «stays until closed or
  acted on», and keyboard users need a way to close a toast that never times out.
- The one-line toast is exact to the board; on a toast that wraps beside an action, the icon and the first line sit 6
  px lower than the board's hand-placed `.w` sample (CSS can't tell a wrapped toast from a one-liner).
