# The results map (P4 slice 5, D3; feat/d3-map)

Book C-04, F-014, F-015, boards Search, Mobile 3.

## What's there

- `pages/search/ui/results-map.tsx`: a pin per place with its next time; the place in hand raised; «Search this area» after the
  person moves the map. The map only stays put while their area is searched; otherwise it follows the results.
- `SearchPage`: from 1024 the map sits beside the list, and a row and its pin light each other. Under it a floating Map opens the
  map over the page with the places as cards, and List goes back. MapLibre isn't loaded on a phone until Map is pressed.
- `MapFrame.onAreaChange`: `[south, west, north, east]` after a person's move. A `zoomed` ref tells the zoom buttons' move from
  a move by `center`, as both come from code. The address says `area=`.

## Traps

- This theme's `sm` is 768 and `md` is 1024, not Tailwind's own.
- Stories draw the ground, so `onAreaChange` can't fire there; `SearchThisArea` and `AreaAfterAMove` run real MapLibre on a
  one-colour `data:` style, no network.

## Left

- Pins that sit on the same spot aren't grouped. The carousel doesn't move the pin as it's swiped (a pin moves the card only).
