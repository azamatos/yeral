# Slice 4 live (P4; 01.11.2026)

Deployed main 7e6feaf (#285) with `PUBLIC=1`; backup `backup-2026-11-01-before-7e6feaf.sql.gz`. The map fix below followed it.

## What the live check found

- **Every map on the live sites was blank** (the business page, and the same `MapFrame` in the app's address settings). The map
  drew, but `maplibre-gl.css` sets `position: relative` on its box, unlayered, which beats Tailwind's layered `absolute`: the box
  had no height and clipped the canvas, and once loaded the drawn ground faded out, leaving the frame's plain grey. Stories draw
  the ground only (`MapTiles style={null}`), so nothing ran MapLibre. `MapFillsTheFrame` runs it with a one-colour `data:` style,
  no network. Any other unlayered library stylesheet can beat a utility the same way.
- No CSP problem: the style, sprites, fonts, a tile and the worker all loaded, and the canvas held real colours. Claude in Chrome's
  console reader showed nothing, but it may not show browser-generated messages, so that alone proves little.

## What this check doesn't cover

  proved on CI's Docker stack (`daily-work.spec.ts`, 1280×720), and the owner's review covers them live, with the install on a
