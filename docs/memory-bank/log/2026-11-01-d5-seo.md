# Search-engine pages and the slice's e2e (P4 slice 5, D5, D6; feat/d5-seo)

Book F-197, plan `log/2026-11-01-slice-5-plan.md`.

## What's there

- `shared/lib/seo.ts`: `sitemapXml`, `robotsTxt`, `businessJsonLd`, each pure and unit-tested.
- `routes/sitemap[.]xml.ts`, `routes/robots[.]txt.ts`: Start server routes; `server.mjs` hands them everything but the assets.
- `sdk.catalog.sitemap()`. A business page says `LocalBusiness` in JSON-LD, without the point when the address is hidden (C-08) and
  without anything for an owner's preview.
- `e2e/tests/discovery.spec.ts`: Home to a category, the 404, a search to a booking at a time, nothing found, the sitemap, robots
  and the JSON-LD on CI's stack. It searches a week, so it doesn't depend on the hour.
