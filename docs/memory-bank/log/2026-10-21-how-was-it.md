# 2026-10-21 · "How was it?" (F-243), the api

- `asksHowItWas()` (`@yeral/domain/lifecycle`): a completed visit still open to a review (30 days), without one, its card
  not closed.
- `GET /v1/me/how-was-it?lang=` → `{ visit }`: the latest such visit, as a booking summary, or null; My bookings and the
  home page read it. `POST /v1/me/bookings/{code}/how-was-it/close`: closed for good for that visit (migration 0042,
  `bookings.how_was_it_closed_at`); the one before it asks next.
- sdk: `bookings.howWasIt(lang)` (under the person's bookings, so a review refreshes it), `bookings.closeHowWasIt()`.
- The cards come with the client site's slices 3 (My bookings) and 5 (home). Stacked on #147 (0041).
