# Design v0.7, piece 2: our own Select and the TimeField (branch `feat/ui-select`)

The owner, 04.11: "I don't like all select blocks u did, u just used default select instead making own perfect" (#28).
DS-Controls → 03 Select · A2 and 04 Time field · A2; `docs/design/CHANGELOG.md` v0.7 → "A2 Select", "A2 TimeField".

- What's there (`packages/ui`):
  - `select/option-list.tsx` — the one list every select draws, on **cmdk** (through the catalog, `pnpm-workspace.yaml`):
    rows 36 (32 for S, 48 on a sheet), one highlight the pointer and ↑ ↓ share (`data-selected`), the chosen row 600 +
    check (a checkbox in a multi-select, `aria-checked`), disabled rows n-400 with their reason in the meta slot, sticky
    group headers (28, 11 caps), search above 8 options (substring on the label and `keywords`, the match 600, × clears,
    «Nothing matches» from the caller's `empty(search)`), opened with the chosen row centred (`SelectLayer`: a Radix
    Popover 4 below, `rounded-popover p-1.5 shadow-raised`, list `max-h-80`; under 768 the repo's `Drawer` as a sheet
    with a handle, the label, a close button, rows 48, search L 48, `max-h-[85%]`).
  - `select/select.tsx` — `Select` (single: `value: string | null`, `onValueChange(value)`, `options: (SelectOption |
    SelectGroup)[]`, `placeholder`, `size` s/m/l = 32/40/48 with `rounded-ctl-*` and `text-ctl-*`, `invalid`,
    `disabled`, `loading`, `icon`, `searchable` (default above 8), `searchPlaceholder`, `empty`, `title` + `closeLabel`
    for the sheet, `listWidth: 'content'` for time lists); `MultiSelect` (`value: string[]`, `label` → the trigger reads
    «Services · 3» in the filter tint, `clearLabel`, `doneLabel` for the sheet's footer); `NativeSelect` = the old native
    control, deprecated, kept for the 19 callers (their import line is `NativeSelect as Select` until they move);
    `selectTriggerClass` / `selectTriggerSize` for the coming FilterButton (A5).
  - `time-field/` — `TimeField` (`value: number | null` minutes, `onValueChange`, `min` / `max` / `step` 15, typing
    tidied on blur or Enter, `invalidMessage` under the field while the text isn't a time, `clock`, the list through
    `SelectLayer` with `anchor` so the focus stays in the input, `aria-activedescendant` read from the list a frame later);
    `parseTime` / `formatTime` in `time.ts` with `time.test.ts` (35 cases). `TimeRangeField` draws two of them (M 40 × 96;
    `size="l"` for 104 on a phone); its step stays 30 until the hours editor (B1) passes 15.
  - The list's name when the caller gives neither `title` nor `aria-label`: `fieldLabelText()` reads the surrounding
    `<Field>`'s label text when the list opens (the sheet's title too), so a Select inside a Field needs no extra props.
  - `lib/cn.ts` now knows `text-ctl-s/m/l` and `rounded-ctl-s/m/l`, `rounded-popover` (tailwind-merge dropped
    `text-ctl-l` next to `text-n-900` before); `cn.test.ts` covers it.
- How the callers move (the next PR, 19 screens + every time picker): `import { Select } from '@yeral/ui/select'`,
  `options={[{ value, label, meta?, disabled? }]}` (groups: `{ label, options }`), `value={String(x)}`,
  `onValueChange={(v) => set(Number(v))}` where the value is a number; a Select inside a `<Field>` needs nothing else,
  one outside a Field needs `aria-label`; under 768 pass `closeLabel` (i18n) — the sheet's title falls back to the
  field's label. Filters (bookings, calendar) take `MultiSelect` with `label`, `clearLabel`, `doneLabel`. Hours, breaks
  and shifts take `TimeField` (or `TimeRangeField`, already moved).
- Traps:
  - cmdk sets `tabIndex=-1` on its listbox after the props; axe wants a scrolling listbox in the tab order, so the ref
    sets `tabIndex = 0`. cmdk's list label defaults to the English «Suggestions»: always pass `label` (an empty string
    when nothing names it). An empty listbox is an axe error: `Command.Empty` sits outside the list and the list is
    `hidden` while nothing matches (`useCommandState`).
  - cmdk marks the highlighted row a pass after mount: anything reading `data-selected` on open (centring, the time
    field's `aria-activedescendant`) runs in `requestAnimationFrame`.
  - Radix Popover's content is `role="dialog"` and needs a name: `SelectLayer` gives it the list's label.
  - A Popover opened from an input (`anchor`) keeps the focus in the input: `onOpenAutoFocus` / `onCloseAutoFocus`
    prevented, `onMouseDown` prevented on the content, `onInteractOutside` ignored for the input itself.
  - Story tests: `userEvent.tab()` and `element.blur()` don't blur the field in the Storybook browser runner; a click on
    `document.body` does. Two comboboxes share a name while a searchable list is open (the trigger and cmdk's input):
    find the search by its placeholder.
