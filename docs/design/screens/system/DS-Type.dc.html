01 · The problem

Onest’s tabular “1” floats in a wide cell

The live apps set numbers in Onest with tabular figures — tables, chips, stats, fields and hours. Tabular figures give every digit the same cell so columns line up. Onest’s cell is 0.67 em, but its “1” is only 0.23 em of ink (0.36 em wide as a normal figure), so every “1” stands in a gap: “1 1:45”, “1,1 70 TMT”, “1 3 bookings”.

Verdict
Every “1” floats
The tabular “1” is 0.23 em of ink in a 0.67 em cell. Proportional Onest would fix running text, but tables, the time grid and timers must stay tabular — and there the gap stays.
Digits fixed, two families on a line
Onest’s colon and comma sit next to Geist digits; every weight loads twice; a unicode-range face to maintain; the companion must be kept in step with Onest’s weights.
One family, even digits
A balanced tabular “1” (0.39 em in a 0.60 em cell), the same cap height and x-height as Onest, ~2.5 % narrower at 400 — screens keep their layout.

Geist replaces Onest — one family

proportional (default) · tabular
Why Geist
01
A balanced tabular “1”. Geist redraws the “1” for tabular use: 0.39 em of ink in a 0.60 em cell. Columns line up and nothing floats.
02
Same size on screen. Cap height 0.71 and x-height 0.53 — the same as Onest (0.707 / 0.527). ~2.5 % narrower at 400, equal at 600–700, so screens keep their layout.
03
Turkmen and Russian in one family. Ä Ç Ň Ö Ş Ü Ý Ž and full Cyrillic, drawn by the same hand as the Latin.
04
One family, one setting. No digit companion, no unicode-range trick, no numeric token. Figures are a font-variant-numeric setting, not a second face.
05
Free and variable. Google Fonts, weights 100–900 in one file; the system stack takes over if it fails to load.
Token
--font-sans: 'Geist', ui-sans-serif, -apple-system,
             'Segoe UI', Roboto, sans-serif;
No numeric token: no --font-num, no digit companion. Tabular figures are switched on per place with font-variant-numeric: tabular-nums (see 04).

04 · Where tabular figures stay

Tabular only where digits line up or tick

Figures are proportional everywhere by default. font-variant-numeric: tabular-nums is set in exactly three places: numeric table columns, the calendar time grid, and running timers and countdowns. Never on phone numbers, prices in text, time chips, dates, stat tiles, the code input or headings. All samples below are Geist.
