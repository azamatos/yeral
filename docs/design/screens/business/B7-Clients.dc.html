What changed and why

  • Tags have their own column and every row is one line, 56 high — tags under the name made the rows tall (“Why are tags under the name? Why are rows so tall?”).
  • The “…” menu is gone. The whole row opens the card, the number copies from the Phone column, the only row action is a New booking icon, and Delete client lives inside the card.
  • Sort and filter by what the table shows: Name, Visits, Last visit and Total sort from the header or Sort; Tag, Upcoming booking and Specialist filter with counts; segments carry counts (All 100 · Regular 34 · New 12 · Lapsed 20 · Reported 2).
  • Show 25 more appends rows in place: the scroll position stays and the URL doesn’t change, so the page no longer jumps.
  • Specialist view keeps the same table minus Total, Add and the Specialist filter; every number counts only her bookings.
  • 1024: the icon rail, Total hidden below 1280 (it returns when it’s the sort), one tag chip then “+N”.
