## Decisions (simplest Fresha-like, please confirm)
- `codeOnScreen` defaults to off (standard SignInCodeStep); turn it on to see the first-release variant. In Play any code except 0000 is right; the rate limit hits on the 4th code request for the same number (another number starts again).
- Play routes after the code: 65 10 20 30 (Maýsa) / Aýna / Selbi / Maral / Jeren → “Opening Glow Studio…”; 64 21 55 90 (Gülnar) → invite; **62 48 15 30 (invented demo number) → “Continue setting up Glow Studio”**; any other mobile number → name → no workspace.
- Leave demo uses Aýna's b03, b05, b06 (today, confirmed) + b18 (tomorrow, pending) and assumes **Gülnar has accepted** (she does 3 of the 4 hair services; Hair colouring has nobody → row falls back to “Cancel and offer 3 other times”).
- The leave toast stays until opened or closed (it needs a decision); the notification item stays until all bookings are settled; the owner and admins with “Manage the team” get it.
- Switching workspace keeps the section (/w/glow-studio/calendar → /w/glow-nails/calendar); opening a /w/{slug} you don't belong to → your last used workspace + “This section is closed to you”; tab title “Calendar · Glow Studio”.
- “Fix and send again” opens the settings section the reason points to; saving sends the page back to review.
- Banners use role="status" (persistent, read once), not alert.
