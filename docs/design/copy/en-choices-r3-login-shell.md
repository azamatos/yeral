## Decided while drawing
- Notifications banner: accent Callout tone for the ask (no dismiss — requests expire), neutral for blocked (can be closed; stays closed in this browser). Shown only to people who may answer requests, under a business status banner when both show.
- Locked or rate-limited code step: the on-screen code callout hides too (the code can’t be used then). In Play, the 6th code request for the same number shows “Too many codes. Try again in 42 minutes.” (static demo minutes).
- “Try the business app” links go to B-Calendar.dc.html (the demo has no artboard of its own; B-Calendar/B-Bookings show it with their `banner: demo` tweak).
- Sidebar counts from the demo data: Owner and Admin 6 requests; Aýna (Specialist) 2 (Ejegyz T. today, Aýjemal G. tomorrow).
- Admin sees no money at all (fixed table), so “unless the owner gives See revenue” is gone; the Specialist sees only her own earnings line in the calendar.
- Remove-staff “Cancel” closes without changes; the Team banner stays until everything is settled.
- The closed switcher keeps the access level under the name (round-2 markup); the open rows show “access level · city”.
- Workspace names in switcher rows stay on one line with an ellipsis (data, not labels) — the only items the long-text check cut.
